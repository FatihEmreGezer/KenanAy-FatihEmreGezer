# Fatih Emre Gezer - Ders Projesi

Bu proje, Web Tasarımı ve Programlama dersi için Next.js, React ve Tailwind CSS kullanılarak geliştirilmiş bir web uygulamasıdır.

## 👤 Geliştirici
- **Fatih Emre Gezer** — GitHub: [@FatihEmreGezer](https://github.com/FatihEmreGezer)

## 🚀 Başlatma

Geliştirme sunucusunu çalıştırmak için:

```bash
npm install
npm run dev
```

Tarayıcınızda [http://localhost:3000](http://localhost:3000) adresini açın.
