# Kenan Ay - Ders Projesi

## 👤 Geliştirici
- **Kenan Ay**

## 🛠️ Kullanılan Teknolojiler
- **Next.js 16** (App Router)
- **React 19**
- **Tailwind CSS v4**
- **TypeScript**

## 🚀 Çalıştırma

1. Gerekli paketleri yükleyin:
```bash
npm install
```

2. Geliştirme sunucusunu başlatın:
```bash
npm run dev
```

3. Tarayıcınızda [http://localhost:3000](http://localhost:3000) adresini açın.
